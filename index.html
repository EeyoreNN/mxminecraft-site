HOW TO CONNECT

Open Minecraft: Java Edition

Use the latest release (26.3) in the launcher. Bedrock (console, phone, the Windows Store version) can't join.

Go to Multiplayer, then Add Server

Name it whatever you like, then type mxminecraft.net as the server address. You don't need a port.

Join

Double-click it. If you see "You are not whitelisted on this server", your request is still waiting on an admin. Check this page again in a bit.
