GET STARTED

Get Minecraft: Java Edition

Open the launcher and play the latest release (26.3). Bedrock (console, phone, Windows Store version) can't join.

Get whitelisted

This server is invite-only. Send your exact Java username to Nick or an admin and wait until they say you've been added.

Add the server

Go to Multiplayer, then Add Server, and type mxminecraft.net as the address. You don't need a port.

Join and play

Double-click MX Minecraft. If it says "not whitelisted", your name hasn't been added yet, so ask again.

RULES

Be cool

No griefing, stealing, or harassment. Build near people only if they're fine with it.

No cheats

No x-ray, hacked clients, or dupes. Performance mods like Sodium and Iris are fine.

Keep it fair

No lag machines. Keep giant farms reasonable so everyone can play.

FAQ

The status says offline

The server runs on a home PC and is sometimes down for updates. Check back later, or ask in the group chat.

"Outdated client/server"

Switch your launcher to the latest release. The badge above shows the server's version.

Where do I live?

The world is pregenerated out to 10,000 blocks, so you can pick a spot and settle.
