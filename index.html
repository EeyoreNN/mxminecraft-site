MISSION BRIEFING

HOW TO CONNECT
STEP 01
Launch Java Edition

Open the latest release (26.3) in the Minecraft launcher. Bedrock (console, phone, the Windows Store version) can't join.

STEP 02
Add the server

Go to Multiplayer, then Add Server, and type mxminecraft.net as the address. You don't need a port.

STEP 03
Deploy

Double-click to join. If it says "not whitelisted", an admin hasn't approved you yet. Check back here.
